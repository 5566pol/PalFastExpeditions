# 幻兽帕鲁自动脚本

由强大的Mimo-v2.5-pro代写（）
自动快速完成帕鲁远征，攻打竞技场，使用Rapid OCR识别屏幕文字并点击操作。

## 环境要求

- Windows 10/11
- ~~Tesseract OCR~~(已弃用)

## ~~安装 Tesseract OCR~~

1. 下载 Tesseract OCR 安装包：
https://github.com/UB-Mannheim/tesseract/wiki
2. 安装时勾选 **Chinese Simplified** 语言包
3. 在程序界面中修改 Tesseract 路径

## 使用方法
### 自动远征
1. 打开程序后，在界面顶部选择远征目的地
2. ~~在界面底部选择 Tesseract 路径~~
3. 幻兽帕鲁里走到远征机面前，确保站在那按下F能显示远征界面，然后什么都不要动
4. 确保游戏为全屏窗口或窗口模式，窗口保证在前台
5. 按 **PageDown（默认）** 键开始/停止自动化流程
### 自动竞技场
1. 打开程序，在顶部选择自动竞技场
2. 在帕鲁选择这里选择你的主站帕鲁与辅助帕鲁（输编号名称都行，暂时不支持泰拉瑞亚联动帕鲁）
3. 选择对手的段位
4. 设置战斗完成时间，这个时间包含从选择完帕鲁点击准备后到比赛打完返回世界的用时
5. 游戏里人走到按F就能进竞技场的位置
6. 按 **PageUp（默认）** 键开始/停止自动化流程
**注意：必须确保人物站原地不会被打死（建议是提前放好无人机或者泰拉棱镜）**
